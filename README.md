Minecraft Paper(Maven) 버전 좀비 사냥 퀘스트 플러그인입니다.

Java와 Paper API를 학습하며 직접 제작한 개인 프로젝트입니다.

예외 상황 처리는 인벤토리에 아이템이 다 찼을 시에 해결하는 것까지만 구현을 해놨습니다.



## 주요 기능
- `/quest 명령어를 통한 퀘스트 시작
- QuestStatus 열거형을 이용한 퀘스트 상태 관리
- 좀비 처치 수 실시간 카운트
- 좀비 10마리 처치 시 퀘스트 완료
- 퀘스트 완료 시 다이아몬드 1개 보상
- 퀘스트 상태에 따른 명령어 메시지
- ActionBar를 통한 진행 상황 표시
- 메시지 디자인 및 사운드 효과
- 인벤토리가 가득 찬 경우 보상 지급 실패 처리 및 재시도 지원


## 향후 개선 사항
- 퀘스트 진행 중 사망 시 처리
- YAML을 이용한 퀘스트 데이터 저장 및 불러오기
- 코드 구조 개선 및 추가 기능 개발

## 개발 목적

Java 기초 문법과 객체지향 프로그래밍을 학습하고
Paper API를 활용한 Minecraft 플러그인 제작 경험을 쌓기 위해 시작한 프로젝트입니다.
